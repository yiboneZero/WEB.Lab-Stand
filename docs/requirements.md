# WEB.Lab-Stand 요구사항

## 제품 목표

정상 라이각으로 세운 퍼터의 길이와 라이각을 각각 독립된 절차로 측정합니다. 길이는 솔 바닥 기준점부터 그립 끝까지의 거리를 골프공 기준 비율로 계산하고, 라이각은 샤프트 양쪽 엣지의 중심선과 보정 수평선 사이의 각도로 계산합니다.

## 측정 모드와 최근 결과

- 시작 화면에서 길이 측정과 라이각 측정을 선택할 수 있어야 합니다.
- 두 측정 절차와 결과 화면은 서로 독립적으로 동작해야 합니다.
- 성공한 길이와 라이각의 최근 결과를 측정 선택 화면에 각각 표시해야 합니다.
- 최근 결과는 브라우저 로컬 저장소에만 보관하며 서버로 전송하지 않습니다.
- 결과 화면에서 같은 항목을 다시 측정하거나 측정 선택 화면으로 돌아갈 수 있어야 합니다.

## 배치 기준

- 퍼터 솔이 평평한 바닥에 자연스럽게 닿아야 합니다.
- 퍼터를 실제 어드레스에 가까운 정상 라이각으로 세웁니다.
- 골프공은 퍼터 측정선과 가능한 한 같은 수직 평면에 둡니다.
- 후면 `1×` 카메라로 정면 촬영하며 초광각과 디지털 줌은 사용하지 않습니다.
- 퍼터 전체와 골프공이 촬영 테두리 안에 들어와야 합니다.

## 자동촬영

- 휴대폰 수직 좌우 오차: `-1.5° ~ +1.5°`
- 휴대폰 수직 앞뒤 오차: `-1.5° ~ +1.5°`
- 안정 유지: 1초
- 카운트다운: 3초
- 흔들림 또는 허용 범위 이탈 시 카운트다운 취소
- 수동 촬영 버튼은 제공하지 않음
- 수직·수평 상태와 레이더는 촬영 프레임 위쪽의 통합 상태 카드에 표시
- 촬영 프레임, 상태 카드, 안내 문구, 닫기 버튼은 동일한 좌우 여백 사용
- 촬영 안내는 프레임 아래에 표시하고 닫기 버튼은 화면 하단 전체 폭으로 제공

## 측정 절차

1. 촬영 테두리 안에 세운 퍼터와 골프공을 배치합니다.
2. 자동촬영 후 테두리 내부만 크롭해 확대 표시합니다.
3. 골프공 주변을 터치하면 검색 영역의 RGB 엣지에서 공의 상단과 좌우 원호를 찾습니다.
4. 하단 검출을 필수로 요구하지 않고 상단·좌우 원호로 중심과 반지름을 계산해 가려진 하단을 복원한 뒤 검출 크기의 `106%`를 기본값으로 표시하고 사용자가 확인합니다.
5. 그립 끝을 선택합니다.
6. 퍼터 솔이 바닥에 닿는 측정 기준점을 선택합니다.
7. 두 선택점을 대형 투명 링으로 드래그해 보정합니다. 두 점 중 골프공 하단 접점과 촬영 수평으로 추정한 지면선에 가까운 점을 헤드 쪽, 먼 점을 그립 쪽으로 매번 판정합니다. 그립 쪽은 헤드에서 그립으로 향하는 축의 가장 바깥쪽에서 여러 탐색선에 반복 검출되는 끝 경계에 스냅하고, 헤드 쪽은 추정 지면선에 가장 가까운 유효 경계에 스냅합니다.
8. 퍼터 픽셀 거리와 공 픽셀 지름의 비율로 길이를 계산합니다.
9. 성공한 결과를 최근 길이 측정값으로 저장하고 측정 선택 화면에 표시합니다.

## 라이각 측정 절차

1. 라이각 측정 모드를 선택하고 퍼터 헤드와 샤프트가 촬영 테두리 안에 들어오도록 배치합니다.
2. 자동촬영 또는 기존 사진 불러오기로 분석할 이미지를 준비합니다.
3. `60°~85°` 범위에서 샤프트의 좌우 엣지가 함께 이어지는 직선 구간을 찾습니다.
4. 헤드에 가까우면서 폭과 직진성이 안정적인 구간의 중심선을 계산합니다.
5. 촬영 시 수평 센서값을 적용해 라이각을 보정하고 검출 신뢰도와 함께 표시합니다.
6. 성공한 결과를 최근 라이각 측정값으로 저장하고 측정 선택 화면에 표시합니다.

## 범위 제외

- 기기 모델·초점거리·카메라 높이 보정
- 센서만을 이용한 카메라 정면 각도 판정
- 길이 측정에서 퍼터와 골프공의 완전 자동 인식
- 공식 경기 또는 제조 검사용 정밀 측정
