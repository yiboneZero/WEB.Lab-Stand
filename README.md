# WEB.Lab-Stand

퍼터 길이와 라이각을 각각 독립적으로 측정하는 모바일 웹앱입니다. 길이는 골프공의 공인 지름 `42.67mm`를 기준으로 계산하고, 라이각은 헤드에 가까운 안정적인 샤프트 양쪽 엣지를 자동 검출해 계산합니다.

- V3 서비스: https://yibonezero.github.io/WEB.Lab-Stand/v3/
- 저장소: https://github.com/yiboneZero/WEB.Lab-Stand
- 대상: iPhone Safari, Android Chrome

## 측정 배치

1. 평평한 바닥에서 퍼터를 정상 라이각으로 세웁니다.
2. 퍼터의 측정선과 골프공이 가능한 한 같은 수직 평면에 오도록 배치합니다.
3. 후면 `1×` 카메라를 퍼터 정면에 놓고 휴대폰을 수직으로 세웁니다.
4. 퍼터 전체와 골프공을 촬영 테두리 안에 넣습니다.
5. 좌우·앞뒤 수직 오차가 각각 `±1.5°` 이내로 1초 유지되면 3초 후 자동 촬영됩니다.
6. 크롭된 사진에서 골프공 주변을 터치해 공을 검출합니다.
7. 그립 끝과 퍼터 솔의 바닥 접촉 기준점을 선택하고 드래그로 보정합니다.

## 계산식

```text
퍼터 길이(mm) = 퍼터 선택점 거리(px) / 골프공 검출 지름(px) × 42.67
```

카메라 높이, 기기 모델 또는 초점거리 보정은 사용하지 않습니다. 퍼터와 골프공이 서로 다른 평면에 있으면 원근 오차가 발생하므로 같은 수직 평면 배치가 중요합니다.

## 주요 기능

- 휴대폰 수직 상태를 두 축으로 확인하는 자동촬영
- 수동 촬영 버튼 없이 `±1.5°`, 1초 유지, 3초 카운트다운 적용
- 안내 테두리 내부만 크롭해 선택 화면에 확대 표시
- 터치한 원형 검색 영역 전체에서 골프공 후보 자동 검출
- 투명한 대형 링으로 그립 끝과 솔 바닥 기준점 선택·드래그
- cm 및 inch 결과와 픽셀 진단값 표시
- 모든 이미지를 브라우저 안에서만 처리

## 현재 제약

- 휴대폰 센서는 기기가 수직인지 확인할 수 있지만 카메라가 퍼터 평면을 정확히 정면으로 보는지는 판단하지 못합니다.
- 골프공과 퍼터 측정선이 같은 수직 평면에 있어야 합니다.
- 공식 클럽 측정 장비를 대체하지 않는 참고용 프로젝트입니다.
