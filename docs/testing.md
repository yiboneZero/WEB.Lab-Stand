# WEB.Lab-Stand 모바일 테스트

테스트 주소: https://yibonezero.github.io/WEB.Lab-Stand/v3/

## 측정 모드

- [ ] 첫 화면에서 길이 측정과 라이각 측정을 선택할 수 있다.
- [ ] 측정 이력이 없을 때 최근 결과 영역이 표시되지 않는다.
- [ ] 길이 측정 완료 후 선택 화면으로 돌아오면 최근 길이 결과만 표시된다.
- [ ] 라이각 측정 완료 후 선택 화면으로 돌아오면 최근 라이각 결과만 표시된다.
- [ ] 페이지를 새로 열어도 같은 브라우저에서는 최근 결과가 유지된다.
- [ ] 결과 화면에서 같은 항목을 다시 측정하거나 측정 선택 화면으로 돌아갈 수 있다.
- [ ] 길이 측정 결과에는 라이각 정보가 표시되지 않는다.
- [ ] 라이각 측정에서는 골프공을 요구하지 않는다.
- [ ] 라이각 측정은 60°~85° 범위에서 샤프트 좌우 엣지를 자동 검출한다.
- [ ] 헤드에 가장 가까우면서 폭과 직진성이 안정적인 구간을 우선 사용한다.
- [ ] 좌우 엣지 평균점으로 만든 중심선과 촬영 수평 보정을 이용해 라이각을 표시한다.
- [ ] 80° 초과 결과에는 확인 안내가 표시된다.

## 촬영 화면

- [ ] 세운 퍼터 전체와 골프공을 같은 평면에 배치하라는 안내가 표시된다.
- [ ] 휴대폰 좌우·앞뒤 수직 상태가 각각 표시된다.
- [ ] 두 축이 `±1.5°` 이내로 1초 유지되면 3초 카운트다운이 시작된다.
- [ ] 수동 촬영 버튼이 표시되지 않는다.
- [ ] 테두리 내부만 크롭되어 선택 화면에 확대 표시된다.

## 골프공 검출

- [ ] 골프공 주변을 터치하면 원형 검색 영역이 표시된다.
- [ ] 공을 직접 누르지 않아도 검색 원 안에 있으면 검출된다.
- [ ] 초록색 검출 원이 공 외곽을 가리지 않고 확인 가능하다.
- [ ] 검출 크기를 조정하거나 다시 선택할 수 있다.

## 퍼터 기준점

- [ ] 골프공 확인 후 그립 끝 선택 안내가 표시된다.
- [ ] 다음 단계에서 퍼터 솔의 바닥 접촉 기준점 선택 안내가 표시된다.
- [ ] 두 기준점의 대형 투명 링을 각각 드래그할 수 있다.
- [ ] 링 내부에서 실제 기준점을 확인할 수 있다.
- [ ] 헤드 기준점은 골프공 하단에서 추정한 지면선에 가까운 솔 경계로 스냅된다.
- [ ] 촬영 당시 좌우 기울기가 있으면 보정된 지면 방향을 헤드 스냅에 사용한다.
- [ ] 확정 버튼을 누른 후에만 결과 화면으로 이동한다.

## 결과와 정확도

- [ ] cm와 inch가 함께 표시된다.
- [ ] 공 검출 지름과 퍼터 선택점 거리가 표시된다.
- [ ] 동일 조건에서 5회 측정해 반복 편차를 기록한다.
- [ ] 줄자 측정값과 비교하고 퍼터·공의 평면 차이와 카메라 정면 오차를 함께 기록한다.
